# API Documentation

## Auth Routes

- **POST** `/api/auth/check-status`
    - Body: `{ email: string }`
    - Response: `{ exists: boolean }`

- **POST** `/api/auth/validate`
    - Body: `{ email: string, code: string }`
    - Response: `{ token: string, user: object }`

- **POST** `/api/auth/recover`
    - Body: `{ email: string }`
    - Response: `{ success: boolean }`

- **POST** `/api/login`
    - Body: `{ usuarioApp: string, password: string }`
    - Response: `{ token: string, user: object }`

## Data Routes (Requires Authorization Header: `Bearer <token>`)

> **Nota de paginación:** Todos los endpoints GET soportan hasta **3000 registros**. SharePoint devuelve 999 por página; el servidor pagina automáticamente hasta el límite.

- **GET** `/api/ordenes-compra`
    - Description: Fetch all Purchase Orders.
    - Response: Array of `OrdenCompra` objects.
    - Fields:
        - `id`: unique SharePoint ID
        - `idUnivoco`: IDUnivoco_OC
        - `usuario`: Usuario_OC
        - `fecha`: Fecha_OC
        - `hora`: Hora_OC
        - `proveedor`: Proveedor_SI (nombre interno real en SharePoint)
        - `cantidadArticulos`: CantidadArticulos_OC
        - `cantidadTotal`: CantidadTotal_OC
        - `precio`: Precio_OC
        - `conversion`: Conversion_OC
        - `status`: Status_OC
        - `versionApp`: Version_OC
        - `mesAnio`: MesAño_OC
        - `creadoPor`: Creator name

- **POST** `/api/ordenes-compra`
    - Description: Create a new Purchase Order.
    - Body:
        - `IDUnivoco`: string (required)
        - `Usuario`: string
        - `Fecha`: string (required)
        - `Hora`: string
        - `Proveedor`: string (required)
        - `CantidadArticulos`: string
        - `CantidadTotal`: string
        - `Precio`: string
        - `Conversion`: string
        - `Status`: string
        - `VersionApp`: string
        - `MesAnio`: string
    - Response: Created object from SharePoint.

- **PATCH** `/api/ordenes-compra`
    - Description: Update an existing Purchase Order.
    - Body:
        - `id`: string (required)
        - `Status`: string (optional) → Status_OC
        - `CantidadArticulos`: string (optional) → CantidadArticulos_OC
        - `CantidadTotal`: string (optional) → CantidadTotal_OC
        - `Precio`: string (optional) → Precio_OC
    - Note: At least one optional field is required. Numbers must be sent as strings.
    - Response: Updated object from SharePoint.
